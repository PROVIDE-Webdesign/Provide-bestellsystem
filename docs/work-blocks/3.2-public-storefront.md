## Nachweise und Grenzen

1. `pnpm check`: lokal bestanden. Formatierung, Linting, Typprüfung, 54 Tests und beide Builds sind
   grün. Der datenbankabhängige Test ist im Standardlauf bewusst übersprungen und läuft im
   gesonderten CI-Datenbankjob mit expliziter `TEST_DATABASE_URL`.
2. Neue SQL-Prüfungen: 38 von 38 in einer ergänzenden PGlite-0.5.8-/PostgreSQL-18.3-Laufzeit
   bestanden. Alle 18 Migrationen wurden dafür unverändert angewandt. Die Laufzeit enthält
   ausschließlich synthetische Daten und eine minimale Nachbildung des Supabase-Auth-Schemas.
3. API-/Treiberintegration: separat bestanden über `pg` und den tatsächlichen Worker-Handler gegen
   dieselbe lokale PostgreSQL-WASM-Laufzeit über einen Loopback-Socket.
4. Diese Ergänzungsnachweise ersetzen den verpflichtenden Supabase-/PostgreSQL-15-Lauf nicht. Docker
   und damit die reguläre Supabase-Testumgebung sind in dieser Sitzung nicht verfügbar.
5. Die Browserprüfung wird mit dem gebauten Anwendungscode im lokalen vinext-/workerd-Devserver und
   synthetischen HTTP-Antworten durchgeführt. Sie ersetzt keinen externen Preview-Rollout.
6. Die tatsächliche Hyperdrive-Konfiguration einschließlich Cache und Laufzeitrechten muss vor einem
   ausdrücklich freigegebenen Preview-Rollout geprüft werden.

## GitHub-Blocker

Das Anlegen des freigegebenen Branches über die verbundene Integration wurde abgelehnt: HTTP 403,
`Resource not accessible by integration`. Der zuvor gelesene Repository-Zugriff meldete
`pull: true`, `push: false`.

Deshalb wurden weder Remote-Branch noch Pull Request oder neue GitHub-Actions-Läufe angelegt. Es
erfolgt kein Merge und keine technische Endfreigabe, bevor die Jobs `check` und `database` für den
tatsächlichen Arbeitsstand nachweislich grün sind.

Schreibzugriff der bestehenden GitHub-Verbindung für dieses Repository herstellen. Danach den
lokalen Arbeitsstand auf den Branch übertragen, Pull Request öffnen, GitHub Actions bis Grün
verfolgen und den freigegebenen Arbeitsblock gemäß Übergabe abschließen. Die fachliche Freigabe muss
dafür nicht erneut eingeholt werden.

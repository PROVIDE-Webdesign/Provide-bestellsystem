Technisch abgeschlossen ist Arbeitsblock 3.4 erst nach erfolgreicher lokaler Gesamtprüfung, Commit,
Push, Pull Request, grünen GitHub-Gates `check` und `database` sowie ausdrücklicher technischer
Endfreigabe. Ein Merge benötigt eine zusätzliche ausdrückliche Erlaubnis und eine SHA-Sperre auf den
geprüften PR-Kopf.

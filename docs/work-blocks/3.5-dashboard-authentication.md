# Arbeitsblock 3.5 – Sichere Dashboard-Anmeldung und MFA-Zugangsgrenze

## Freigabe und Ziel

Der Umfang wurde am 15. September 2026 formal freigegeben. Arbeitsblock 3.5 schafft den ersten
geschützten Restaurant-Dashboard-Zugang über Supabase Auth, serverseitige Tokenprüfung, aktuelle
Mitgliedschaft, Rollen, Standortumfang und MFA.

## Enthaltener Umfang

| Bereich     | Umsetzung                                                                         |
| ----------- | --------------------------------------------------------------------------------- |
| Dashboard   | vinext-/Cloudflare-Anwendung mit Anmeldung, Abmeldung und geschütztem Grundgerüst |
| Sitzung     | PKCE-fähige Supabase-SSR-Cookies, serverseitige Claims-Prüfung und Refresh-Grenze |
| MFA         | TOTP-Einrichtung und Challenge; Owner/Manager benötigen `aal2`                    |
| API         | `GET /v1/dashboard/access-context` mit erneuter JWT-/JWKS-Prüfung                 |
| Datenbank   | Service-only-Projektion für Mitgliedschaft, Zugriffsstatus und Standorte          |
| Datenschutz | Minimale Zustände vor MFA/Suspendierung; keine Tokens oder TOTP-Daten in Logs     |
| Nachweis    | Unit-, Contract-, API-, pgTAP-, Integrations- und Build-Prüfungen                 |

## Ausgeschlossen

1. Bestellliste, Bestelldetails oder Statusänderungen.
2. Personalverwaltung, Einladungsversand oder PROVIDE-Administration.
3. MFA-Wiederherstellung und Entfernen des letzten Faktors.
4. Benachrichtigungen, Lieferung, Onlinezahlung und externe Integrationen.
5. Echte Auth-Benutzer, produktive Supabase-Konfiguration oder Deployment.
6. Änderungen am getrennten Asian-Kitchen-Projekt.

## Abschlussbedingung

Technisch abgeschlossen ist Arbeitsblock 3.5 erst nach erfolgreicher lokaler Gesamtprüfung, Commit,
Push, Pull Request, grünen GitHub-Gates `check` und `database` sowie ausdrücklicher technischer
Endfreigabe. Ein Merge benötigt eine zusätzliche ausdrückliche Erlaubnis und die SHA-Sperre auf den
geprüften PR-Kopf.

## Fortschrittswirkung

Bis zur technischen Endfreigabe bleibt die gewichtete MVP-Schätzung bei **60 Prozent**. Nach dem
Abschluss steigt sie voraussichtlich auf **65 Prozent**. Danach verbleiben ungefähr 35 Prozent für
operative Bestellbearbeitung, Benachrichtigungen, Lieferung, Onlinezahlung sowie
Preview-/Produktionsreife. Die Restunsicherheit beträgt ungefähr zwei Prozentpunkte.

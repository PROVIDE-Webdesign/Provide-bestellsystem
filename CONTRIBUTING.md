# Mitwirkung

Das Repository ist öffentlich sichtbar, aber proprietär. Unaufgeforderte Beiträge werden derzeit
nicht angenommen. Eine öffentliche Sichtbarkeit oder ein Fork erteilt keine weitergehenden
Nutzungsrechte.

Fehlerberichte dürfen keine Zugangsdaten, personenbezogenen Daten oder nicht öffentlichen
Sicherheitsdetails enthalten. Sicherheitsprobleme werden nach `SECURITY.md` gemeldet.
